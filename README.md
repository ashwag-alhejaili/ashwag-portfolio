# Ashwag Alhejaili Portfolio

Static portfolio website prepared for GitHub Pages.

## Before publishing
Open `index.html` and replace:
- `https://github.com/YOUR-USERNAME` with your GitHub profile URL.
- `https://www.linkedin.com/in/YOUR-LINKEDIN` with your LinkedIn profile URL.
- `YOUR-CV-LINK` with a public PDF link for your CV.

The email link is already set to `info@ashwag-analytics.com`.

## Publish with GitHub Pages
1. Create a new public repository, e.g. `portfolio` or `ashwag-analytics`.
2. Upload every file/folder in this package to the repository root.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`, then Save.
6. Wait a minute or two for the GitHub Pages URL.

## Custom domain
After GitHub Pages is working, add `ashwag-analytics.com` under Settings → Pages → Custom domain. GitHub will show/validate the DNS configuration. Then update the DNS records at your domain provider.
